# Case study thực tế

Mỗi file là một tình huống đã gặp khi dùng bộ skill: bối cảnh, cách đã làm, kết quả, bài học.

- **Tên file:** `YYYY-MM-DD-<slug>.md`, ví dụ `2026-11-05-nhan-du-an-khong-tai-lieu.md`.
- **Không ghi** tên khách hàng, tên công ty, mã nguồn nội bộ hay thông tin bí mật. Thay bằng mô tả chung, ví dụ "một hệ thống quản lý đơn hàng", "module duyệt nhiều cấp".
- Khi một case study được dùng nhiều lần, đưa phần tổng quát của nó vào `docs/matt-pocock-skills-onboarding.md`.

## Mẫu

```md
# <Tên tình huống>

**Ngày:** YYYY-MM-DD · **Phiên bản skill:** <commit trong skills-lock.json hoặc ngày cập nhật>

## Bối cảnh
<Đầu vào có gì, muốn đạt gì.>

## Cách làm
<Skill nào, theo thứ tự nào, prompt chính.>

## Kết quả
<Ra được gì: tài liệu, ticket, code. Chỗ nào chạy tốt, chỗ nào không.>

## Bài học
<Lần sau làm khác đi thế nào.>
```
